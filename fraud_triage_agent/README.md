# Fraud Triage Agent

Orchestrator + 3 sub-agents (SHAP interpreter, historical lookup, model drift).

```
fraud_triage_agent/
  config.py          paths (Drive), thresholds, column names
  agents/            orchestrator.py, subagents.py
  tools/             deterministic data tools (no LLM)
  schemas/           Pydantic output contracts
  guardrails/        input + output validation
  prompts/           versioned prompts
  ui/                Streamlit app
  utils/             audit log
  evals/             offline evaluation suite + golden_set.csv
  tests/             pytest
  audit_logs/        JSONL audit trail (git-ignored)
```

## Data location
Set `FRAUD_DATA_DIR` (default: the Google Drive `model_output` folder; in Colab run
`drive.mount('/content/drive')` first). Locally, point it at a downloaded copy.

## LangSmith and LLM
Set `LANGSMITH_TRACING=true` and `LANGSMITH_API_KEY` in `.env`, plus ONE destination:
either `LANGSMITH_PROJECT`, or `LANGSMITH_AGENT_ID` with `LANGSMITH_AGENT_ENVIRONMENT`
(setting both makes LangSmith drop all traces). This traces the LangGraph run and its
sub-agents. Set `OPENAI_API_KEY` to enable the
optional qualitative LLM interpretation. Without the key, deterministic summaries
still work and the UI reports that LLM narration was skipped. Never commit `.env`.

## Run
```
pip install -r fraud_triage_agent/requirements.txt
pytest fraud_triage_agent/tests
python -m fraud_triage_agent.evals.run_evals      # add --langsmith to log an experiment
streamlit run fraud_triage_agent/ui/streamlit_app.py
```

## Recommendation rules
Probability above 95%: "keep blocked". Between 86% and 95%: similar-case TP share of 50% or more gives
"Likely fraud, review recommended", otherwise "Likely false alarm, review recommended". With no TP/FP
matches the agent asks for manual review. The rule is deterministic (`tools/recommendation.py`).

## Evaluation results
- Invariants: all 12,155 blocked transactions pass all 8 consistency checks.
- Retrieval (leave-one-out on validation SHAP): 68.7% accuracy vs 58.2% majority baseline.
- Guardrails: 8/8 cases pass.
- Golden set (226 analyst labels, feature-based heuristic): 38% agreement. It mostly shows that labels
  built from Count_C1/velocity do not match the SHAP-neighbour history; it is not model accuracy.

## Behavior and limitations
- SHAP, historical lookup, drift, and all numeric statements are generated by Python tools.
- LangGraph runs SHAP lookup and historical retrieval in parallel, then drift and finalization.
- Optional LLM output is a separate qualitative interpretation; it cannot add numbers.
- The historical TP share uses TP/(TP+FP); FN matches are not part of that denominator.
- The validation file has no TransactionID, so similar cases are identified by `Val_Index`.
- Decision support only: an analyst confirms every action.
- Not yet built: user feedback capture, CI, container image.
